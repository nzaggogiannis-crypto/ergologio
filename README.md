# ΕργοΛόγιο

Εφαρμογή διαχείρισης εργοταξίων της ΔΥΡΑΣ ΤΕΧΝΙΚΗ ΟΕ: έργα, τιμολόγια, ημερολόγιο εργαζομένων, προμηθευτές, πελάτες, αυτοκίνητα.

- Σελίδα: `index.html` (στατική, GitHub Pages)
- Σύνδεση χρηστών και δεδομένα: Google Firebase (Authentication + Firestore)
- `firestore.rules`: οι κανόνες ασφαλείας της βάσης (αντίγραφο αυτών που έχουν μπει στο Firebase console)

Ο κώδικας είναι δημόσιος· τα δεδομένα δεν είναι. Φαίνονται μόνο σε όσους έχει εγκρίνει ο διαχειριστής.
